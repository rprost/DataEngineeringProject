# Steam games and player counts

**Group 9 | Data Engineering Project 1**

Proposed data architecture and star schema for analysing Steam game popularity and monthly player activity.

Sources: [SteamSpy API](https://steamspy.com/api.php), Steam Store API and [historical player data from Kaggle](https://www.kaggle.com/datasets/jackogozaly/steam-player-data).

- `P1_Group_9.pdf` - project report.
- `sql/schema.sql` - PostgreSQL table definitions.
- `sql/queries.sql` - queries for the five business questions.
- `data/` - ten raw sample rows from each dataset. SteamSpy prices are in USD cents.

See the PDF (P1_Group_9.pdf) for the full project description.
